# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

Fork the repository, create a new branch for your feature or fix, make your changes and commit them with clear and descriptive messages, push your branch to your fork, then open a pull request describing your changes and why they are needed.

## Reporting Bugs

Please open an issue describing the problem, the steps to reproduce it, and details about your environment.

## Suggesting Enhancements

Ideas for new features or improvements are always welcome. Open an issue to start a discussion before submitting a large pull request.

## Code Style

Keep changes small and focused, and add comments where the intent of the code is not obvious.

Thank you for helping improve this project!
