# github-final-project

## Simple Interest Calculator

This project contains a Simple Interest Calculator implemented as a Bash script (simple-interest.sh). Simple interest is calculated using the formula: Simple Interest = (Principal * Rate * Time) / 100, where Principal (P) is the initial amount of money, Rate (R) is the annual rate of interest expressed as a percentage, and Time (T) is the time period in years.

## How It Works

The script prompts the user to enter the principal amount, the annual rate of interest, and the time period in years. It then computes the simple interest using the formula above and prints the result to the terminal.

## Example Usage

Input:
   p, principal amount
      r, annual rate of interest
         t, time period in years
         Output:
            simple interest = (p * r * t) / 100

            Example:
               $ ./simple-interest.sh
                  Enter the principal amount: 1000
                     Enter the rate of interest (in %): 5
                        Enter the time period (in years): 2
                           Simple Interest  : 100.00
